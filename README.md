# Оникс

Свой «Obsidian» в браузере: заметки в Markdown, несколько пользователей, общие хранилища, установка как PWA.

## Запуск

```bash
cp .env.example .env        # и поменяйте POSTGRES_PASSWORD
docker compose up -d --build
```

Приложение откроется на <http://localhost:8081>. Первый шаг — «Регистрация»: логин и пароль.
Данные лежат в томе `pgdata` (PostgreSQL 17), база наружу не публикуется.

| Переменная (`.env`)  | По умолчанию | Что делает                                                        |
| -------------------- | ------------ | ----------------------------------------------------------------- |
| `APP_PORT`           | `8081`       | Внешний порт                                                      |
| `POSTGRES_PASSWORD`  | `onyx`       | Пароль базы — задайте свой до первого запуска                     |
| `SESSION_DAYS`       | `365`        | Срок жизни входа; продлевается при каждом посещении (максимум 400) |
| `ALLOW_REGISTRATION` | `true`       | `false` закрывает регистрацию (первый пользователь проходит всегда) |
| `MAX_UPLOAD_MB`      | `50`         | Предел размера одного загружаемого файла                          |

> Установка как приложение (PWA), работа оболочки без сети и чтение буфера обмена из меню требуют
> **https** или `localhost` — это ограничение браузеров. Для доступа с телефона поставьте перед портом 8081
> обратный прокси с сертификатом (Caddy, Traefik, nginx): cookie сессии сама станет `Secure`.

Резервная копия: `docker compose exec db pg_dump -U onyx onyx > backup.sql`, либо кнопка «Выгрузка → Всё хранилище».

## Что внутри

- **Редактор** — CodeMirror 6 с «живым просмотром» как в Obsidian: разметка прячется, пока курсор не встанет на элемент.
  Заголовки, жирный/курсив/зачёркнутый, `==выделение==`, код, цитаты и врезки `> [!note]`, списки, задачи с флажками,
  таблицы, `[[вики-ссылки]]` с подсказкой, `![[вставки]]` картинок, `#теги`, YAML-свойства. Три режима: живой просмотр, исходник, чтение.
- **Форматы** — Markdown основной; любой другой текст (`.txt`, `.json`, `.yaml`, `.csv`, код) открывается с подсветкой.
  Картинки, PDF, аудио и видео — встроенным просмотрщиком. Вставка картинки из буфера создаёт вложение.
- **Контекстное меню** — в дереве файлов, на вкладках и в редакторе (правая кнопка; на телефоне — долгое нажатие, меню выезжает снизу).
- **Выгрузка** — кнопка в шапке: исходный файл, самодостаточный HTML, печать/PDF, папка или всё хранилище в `.zip`.
  Обратно: загрузка файлов, папок и zip-архивов (в том числе готового хранилища Obsidian).
- **Многопользовательский режим** — у каждого свои хранилища; хранилищем можно поделиться по логину (редактор или читатель).
  Изменения приходят по WebSocket сразу, одновременные правки одного файла сливаются, видно, кто сейчас в заметке.
  Переименование файла обновляет ссылки на него во всех заметках.
- **Граф связей** — весь граф хранилища или только окружение открытой заметки (глубина 1–3): зум, панорама, перетаскивание узлов,
  поиск, ещё не созданные заметки пунктиром. Щелчок по узлу открывает заметку.
- **Шаблоны** — восемь готовых (ежедневная заметка, встреча, проект, итоги недели, конспект книги, решение, человек, идея) и свои:
  любая заметка в папке «Шаблоны» — шаблон. Переменные `{{date}}`, `{{date:D MMMM YYYY}}`, `{{time}}`, `{{title}}`, `{{user}}`, `{{cursor}}`.
  «Заметка на сегодня» создаёт файл дня в папке «Дневник».
- **Поделиться** — заметкой или папкой: ссылка для всех (навсегда или на срок, со счётчиком просмотров) либо доступ конкретному
  человеку по логину. Всё только для чтения, открывается на отдельной странице `/s/…` без интерфейса приложения.
- **Профиль и активность** — карта правок за год в духе контрибуций GitHub, серии дней, список правок за выбранный день.
  Профиль можно открыть для всех (`/u/логин`) и показать в нём выбранные заметки.
- **История версий** — снимок текста делается при возвращении к заметке после паузы или когда её начинает править другой человек;
  версии можно сравнить с текущим текстом и восстановить.
- **Оформление** — тёмная/светлая тема, три стиля (Графит, Полночь, Бумага), акцентный цвет, шрифты, размер, ширина строки,
  скругления, переключатели анимаций/волны нажатия/свечения/стекла, свой CSS. Настройки синхронизируются между устройствами.
- **Телефон** — масштабирование и горизонтальная прокрутка отключены, панели — выезжающие шторки со свайпами,
  панель форматирования держится над клавиатурой, учитываются вырезы экрана.

## Горячие клавиши

`Ctrl+O` файл · `Ctrl+P` команды · `Ctrl+E` чтение/правка · `Ctrl+Shift+F` поиск по хранилищу · `Ctrl+F` поиск в заметке ·
`Alt+N` новая заметка · `Alt+T` шаблоны · `Alt+D` заметка на сегодня · `Alt+G` граф · `Alt+W` закрыть вкладку · `F2` переименовать · `Ctrl+\` дерево файлов · `Ctrl+B / I / K` жирный, курсив, ссылка.

Дерево файлов: щелчок выделяет строку, `Ctrl`+щелчок добавляет к выделению, `Shift`+щелчок — диапазон; стрелки, `Enter`, `F2`, `Delete` работают
по выделенному, перетаскивание и «Переместить…» — сразу по всем выделенным. Новая заметка создаётся в выделенной папке.

## Разработка

```bash
docker compose up -d db                      # только база (порт нужно опубликовать самому)
cd server && npm ci && npm run build && DATABASE_URL=postgres://onyx:onyx@localhost:5432/onyx npm start
cd client && npm ci && npm run dev           # Vite проксирует /api на http://127.0.0.1:8081
```

- `server/` — Fastify + TypeScript: API, сессии (cookie, хеш токена в базе, пароли — scrypt), WebSocket, zip. Схема — в `server/src/db.ts`.
- `client/` — Preact + TypeScript + Vite. Редактор — `src/editor/`, рендер для чтения и выгрузки — `src/render/`, темы — `src/styles/base.css`.
